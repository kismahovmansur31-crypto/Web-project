Веб-приложение на Python для хранения персональных фотографий с эффектом полароида. Функционал: Ограничение объема: максимум 6 фотографий на один сайт. Автоматическая обработка: кадрирование любого изображения в ровный квадрат через библиотеку Pillow и сохранение файла при загрузке. Интерактивные подписи: возможность вводить текст прямо в нижнюю белую часть карточки с автоматическим сохранением на сервере при потере фокуса. Интерфейс: размытый и затемненный фоновый рисунок в стиле Glassmorphism с аккуратной сеткой из 6 слотов, которые плавно увеличиваются и наклоняются при наведении мыши. Пустые места обозначены заглушками со значком плюса. Стек технологий: Бэкенд: Python (Flask). Обработка изображений: Pillow (PIL). Фронтенд: HTML, CSS (Grid/Flexbox) и шаблонизатор Jinja2. Логика работы: Программа проверяет наличие сохраненных картинок и текстовых файлов в локальной папке static/uploads для каждого из 6 слотов. Если изображение найдено, Jinja2 выводит готовый полароид с сохраненным текстом. Если файла нет, отображается пустой слот с плюсом. При выборе картинки она отправляется на сервер, преобразуется в формат полароида и перезаписывает файл ячейки, а введенный текст сохраняется в обычный файл .txt.
